# 🏨 فندق الضيافة | Al-Diyafa Luxury Hotel

موقع ويب فندقي فاخر متكامل وثنائي اللغة (العربية والإنجليزية)، مبني بأحدث معايير الويب باستخدام **HTML5** و **CSS3** و **JavaScript (Vanilla)** مع دعم كامل لاتجاهات القراءة (RTL / LTR).

---

## 🌟 مميزات المشروع

- **الأركان الأربعة للتصميم**:
  - 🎨 **لوحة ألوان فندقية ملكية**: الذهبي الفاخر (`#C8A456`) والكحلي الملكي (`#1B2A4A`) وخلفيات دافئة مريحة للعين.
  - ✒️ **طباعة متميزة (Typography)**: خط `Tajawal` للغة العربية و `Playfair Display` للعناوين الإنجليزية و `Poppins` للنصوص.
  - 🖥️ **تصميم واجهات احترافي (UI)**: هيكلة أنيقة، تأثيرات زجاجية (Glassmorphism)، أزرار وظلال ناعمة وتخطيط دقيق.
  - 🧑‍💻 **تجربة مستخدم تفاعلية (UX)**: تبديل سلس وفوري بين اللغتين (العربية / English)، قوائم متجاوبة للهواتف، نماذج تفاعلية، ومعرض صور بملء الشاشة (Lightbox).

---

## 📄 صفحات الموقع

1. **الصفحة الرئيسية (`index.html`)**: شريط تنقل ذكي، واجهة ترحيبية جذابة مع نموذج بحث وحجز سريع، استعراض لأبرز الغرف والخدمات، سلايدر لآراء النزلاء.
2. **الغرف والأجنحة (`pages/rooms.html`)**: فلترة تفاعلية فورية حسب فئة الغرفة (قياسية، سوبريور، أجنحة) مع تفاصيل المساحة والأسرة والأسعار.
3. **من نحن (`pages/about.html`)**: قصة الفندق، الرؤية والرسالة والقيم، عدادات إحصائية رقمية متحركة، وفريق الإدارة التنفيذي.
4. **الخدمات والمرافق (`pages/services.html`)**: شبكة لجميع الخدمات بالإضافة إلى تبويبات تفاعلية تستعرض المطعم، السبا، المسبح، والنادي الرياضي.
5. **معرض الصور (`pages/gallery.html`)**: معرض صور شبكي مدعوم بفلاتر للأقسام وميزة تكبير واستعراض الصور (Lightbox).
6. **تواصل معنا (`pages/contact.html`)**: تفاصيل قنوات الاتصال المباشرة، خريطة موقع تفاعلية، ونموذج إرسال رسائل وتحقق متقدم.

## 🛠️ هيكلية الملفات

```
hotel/
├── index.html                  # الصفحة الرئيسية
├── README.md                   # دليل المشروع
├── pages/
│   ├── rooms.html              # صفحة الغرف والأجنحة
│   ├── about.html              # صفحة من نحن
│   ├── services.html           # صفحة الخدمات
│   ├── gallery.html            # صفحة معرض الصور
│   └── contact.html            # صفحة التواصل
└── assets/
    ├── css/
    │   ├── variables.css       # متغيرات الألوان والمسافات والخطوط
    │   ├── base.css            # القواعد الأساسية وإعادة التعيين (Reset)
    │   ├── layout.css          # الشبكات والتخطيط العام
    │   ├── components.css      # تصميم المكونات (أزرار، بطاقات، نافبار، فوتر)
    │   ├── rtl.css             # التوافق مع اللغة العربية واتجاه اليمين
    │   └── responsive.css      # التجاوب مع شاشات الجوال والأجهزة اللوحية
    ├── js/
    │   ├── i18n.js             # محرك الترجمة الثنائية وحفظ التفضيل
    │   ├── navbar.js           # القائمة المتجاوبة والتمرير الذكي
    │   ├── slider.js           # شريط تقييمات العملاء التفاعلي
    │   ├── gallery.js          # فلاتر المعرض ومستعرض الصور المكبر (Lightbox)
    │   ├── booking.js          # التحقق من صحة النماذج والتواريخ
    │   ├── animations.js       # حركات الظهور التلقائي والعدادات الرقمية
    │   └── main.js             # التهيئة الشاملة للموقع
    └── lang/
        ├── ar.json             # قاموس النصوص العربية
        └── en.json             # قاموس النصوص الإنجليزية
```

## 🚀 كيفية التشغيل

المشروع لا يتطلب أي بيئة تثبيت معقدة (Node.js أو حزم إضافية). يكفي فتح ملف `index.html` في أي متصفح حديث (Chrome, Firefox, Edge, Safari) أو تشغيله عبر خادم محلي مثل `Live Server` في VS Code لتفعيل قراءة ملفات الـ JSON بالكامل.
